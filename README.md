## Research Interests

I work on robot skill learning, behavior trees, foundation models for robotics, and interested in causality-aware autonomous decision making. 
My goal is to build robot skill and behavior coordination systems that can be deployed and scaled in the real world — and one day, robots with human-level tool-use and craftsmanship.

- Robot skill learning for manipulation, tool-use, and craftsmanship
- Behavior trees for reactive manipulation and task planning
- Causality-aware autonomous decision making
